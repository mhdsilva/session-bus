Commands used:

```sh
pnpm --filter @session-bus/mcp cli install codex --project /tmp/session-bus-acceptance/codex
pnpm --filter @session-bus/mcp cli install opencode --project /tmp/session-bus-acceptance/opencode
SESSION_BUS_DB=/tmp/session-bus-acceptance/session-bus.sqlite SESSION_BUS_PORT=7345 pnpm --filter @session-bus/hub start
pnpm --filter @session-bus/web dev
```

Codex was run non-interactively with its project-local MCP entry supplied as an explicit CLI config override and `--approve-for-me`; OpenCode was run with `opencode run --dir <project> --model opencode/big-pickle`. The Codex project was temporary and not already trusted, so the explicit override was needed to load its MCP entry. OpenCode's MCP profile reported version `unknown` because that is the installer default; the installed CLI version was independently checked with `opencode --version`.
